# Кінощоденник

Приватний особистий сайт для запису та оцінки переглянутих фільмів і серіалів.
Пошук назв через TMDB, дані зберігаються у твоїй власній безкоштовній базі Supabase
(доступ з будь-якого пристрою), вхід — за поштою й паролем.

Технології: чистий HTML/CSS/JS, без збірки. Хоститься на GitHub Pages.

## Як це працює і чому це приватно

- Сам сайт (HTML/CSS/JS-файли) буде видно будь-кому, хто знає посилання — так влаштований GitHub Pages.
  Але це просто порожня "оболонка" застосунку без жодних твоїх даних.
- Дані (список фільмів, оцінки, нотатки) лежать окремо, у Supabase, і захищені паролем:
  без входу в акаунт побачити чи змінити їх неможливо — це забезпечує Row Level Security
  на рівні бази даних, а не просто екран входу в браузері.
- Тобто навіть якщо хтось випадково знайде посилання на сайт, він побачить лише форму входу.

## Крок 1. Створи проєкт Supabase (безкоштовно)

1. Зареєструйся на [supabase.com](https://supabase.com) → **New project**.
2. Обери назву, пароль бази (збережи його) і регіон (найближчий до тебе).
3. Після створення проєкту зайди в **Project Settings → API**.
   Скопіюй звідти **Project URL** та **anon public** ключ.
4. Відкрий `config.js` у цьому проєкті та встав їх:
   ```js
   const CONFIG = {
     SUPABASE_URL: "https://xxxxxxxx.supabase.co",
     SUPABASE_ANON_KEY: "eyJhbGciOi...",
     TMDB_API_KEY: "..."
   };
   ```

## Крок 2. Створи таблицю в базі даних

1. У Supabase зайди в **SQL Editor → New query**.
2. Скопіюй туди весь вміст файлу [`supabase-schema.sql`](./supabase-schema.sql) і натисни **Run**.
   Це створить таблицю `diary_entries` і правила безпеки (RLS), які дозволяють
   кожному користувачу бачити тільки свої записи.

## Крок 3. Отримай ключ TMDB (для пошуку фільмів)

1. Зареєструйся на [themoviedb.org](https://www.themoviedb.org) → у налаштуваннях профілю
   відкрий вкладку **API** → запроси **API Key (v3 auth)** (безкоштовно, миттєво).
2. Встав отриманий ключ у `config.js` як `TMDB_API_KEY`.

## Крок 4. Виклади на GitHub

1. Створи новий репозиторій на GitHub (можна приватний).
2. Заливай усі файли з цієї теки в репозиторій.
3. Зайди в **Settings → Pages** репозиторію → у **Source** обери гілку `main` і теку `/root` → Save.
4. Через хвилину сайт зʼявиться за адресою на кшталт `https://твій-нік.github.io/назва-репо/`.

   ⚠️ Важливо: безкоштовний GitHub Pages для **приватного** репозиторію не завжди доступний
   (потрібен план GitHub Pro/Team/Enterprise, щоб Pages теж були приватними).
   Якщо в тебе безкоштовний акаунт — Pages-сайт технічно буде публічним за посиланням,
   але це не страшно: як пояснено вище, без пароля до твоїх даних нікому не дістатись.
   Якщо хочеш, щоб і сам сайт був недоступний стороннім — потрібен платний план GitHub
   або інший хостинг з обмеженим доступом (напр. Netlify з паролем на сайт).

## Крок 5. Створи свій акаунт

1. Відкрий сайт → натисни **«Немає акаунта? Створити»** → введи свою пошту й пароль.
2. Якщо в Supabase увімкнене підтвердження пошти — перевір скриньку і підтверди.
3. **Після того, як створив свій єдиний акаунт**, зайди в Supabase:
   **Authentication → Providers → Email** і вимкни **«Allow new users to sign up»**
   (або в новіших версіях — **Authentication → Settings**). Це закриє реєстрацію
   для будь-кого іншого, хто випадково знайде сайт.

## Використання

- **+ Додати** — шукаєш назву через TMDB (постер, рік підтягуються автоматично)
  або тиснеш «Ввести назву вручну», якщо фільму немає в базі.
- Обираєш статус (у планах / дивлюся / переглянуто), ставиш оцінку 0–10, пишеш нотатку.
- Клік на назву в списку — редагувати або видалити запис.
- Фільтри зверху — за статусом і швидкий пошук по власному списку.

## Локальна перевірка перед публікацією

Просто відкрий `index.html` у браузері — можна тестувати без деплою,
головне щоб `config.js` вже містив реальні ключі.
